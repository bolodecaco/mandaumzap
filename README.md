# mandaumzap

Mandaumzap é uma aplicação full-stack desenvolvida como projeto integrador do curso de Análise e Desenvolvimento de Sistemas (ADS) no IFRN. O sistema permite o envio automatizado de mensagens via WhatsApp, oferecendo uma interface web para gerenciamento de contatos e mensagens.

## Funcionalidades principais

- Envio automatizado de mensagens via WhatsApp Business API

- Gerenciamento de contatos e listas de envio

- Monitoramento do status de envio e recebimento de mensagens

- Armazenamento de histórico de mensagens e logs

- Autenticação segura utilizando JWT

- Containerização com Docker para fácil implantação

## Tecnologias utilizadas

- Backend: Node.js, Express, Spring Boot

- Frontend: Next.js

- Banco de Dados: MongoDB, PostgreSQL

- Autenticação: JWT (JSON Web Tokens), Keycloak

- Infraestrutura: Docker, Docker Compose
